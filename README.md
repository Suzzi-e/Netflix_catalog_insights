# Netflix Content Analysis

## Project Context and Acknowledgements

This Netflix content analysis project was developed using tasks provided through Auspify Technologies' Data Analysis internship programme.

The project demonstrates practical work in Python, data cleaning, exploratory data analysis, data visualization, business insights, and interactive dashboard development.

The original dataset was provided through the programme's Google Drive resources. Their official website: [Auspify Technologies](https://auspify.com/)

This repository showcases my project work and learning.

## Project Tasks

* **Task 1:** Data collection and cleaning
* **Task 2:** Exploratory data analysis
* **Task 3:** Content trends and patterns
* **Task 4:** Data visualisation and analysis
* **Task 5:** Further analysis and insights
* **Task 6:** Interactive Dashboard

## Tools and Technologies

* Python
* Pandas
* Seaborn
* Matplotlib
* Plotly
* Streamlit
* Jupyter Notebook

## Interactive Dashboard

The Streamlit dashboard allows users to explore Netflix catalogue patterns using interactive charts and filters.

## Project Files

* `Netflix_Task1.ipynb` – `Netflix_Task5.ipynb`: Analysis notebooks
* `app.py`: Streamlit dashboard application
* `cleaned_dataset.csv`: Cleaned dataset used by the dashboard
* `requirements.txt`: Python dependencies

## Running the Dashboard Locally

1. Clone or download this repository.

2. Install the dependencies:

   `pip install -r requirements.txt`

3. Run the dashboard:

   `streamlit run app.py`

## Dataset

The dashboard uses `cleaned_dataset.csv`. Refer to the website above for the original dataset source.
